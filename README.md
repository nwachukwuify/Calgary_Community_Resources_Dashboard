# Calgary_Community_Resources_Dashboard
A centralized, interactive platform that brings together essential services across the city into one accessible place.
Data for Good YYC | Micro Project Cohort 5
### Project Context
For many Calgary residents and newcomers, accessing essential services is hindered by fragmented information and language barriers. Support exists, but it is often "hidden" across scattered platforms. As part of Data for Good YYC, our team engineered a centralized, interactive solution to bridge this information gap.

### The Solution
Developed the Calgary Community Resources Dashboard: a scalable, geospatial platform that centralizes food support, healthcare, childcare, and community programs into a single source of truth.

### Technical Stack & Engineering Workflow
This project utilized an end-to-end data pipeline to ensure data accuracy and accessibility:

Data Processing: Python (Pandas/NumPy) for cleaning and normalizing fragmented community datasets.

Geospatial Analysis: Leveraged Python libraries and Google Cloud technologies to calculate distances and map service density.

Visualization: Power BI for the front-end interactive interface.

Localization: Integrated multi-language support to lower the barrier of entry for diverse populations.

### Key Features
Geospatial Intelligence: Interactive map for real-time service location and distance calculation.

Accessibility First: Multilingual toggle to support Calgary's diverse newcomer population.

Direct Connectivity: Integrated API-like links to service providers for immediate action.

Strategic Audit View: A dedicated analytical layer for policymakers to identify "service deserts" and resource gaps within specific neighborhoods.

### Real-World Impact
This project transitioned fragmented data into a community asset, resulting in:

Reduced Search Latency: Drastically cut the time required for residents to find emergency services.

Data-Driven Policy: Empowered community organizations with insights into service distribution and demographic needs.

Improved Inclusivity: Removed language barriers that previously prevented vulnerable groups from accessing aid.

### Project Disclaimer
